# Docs

这里集中放置项目资料和交付文档。AI 开发规则、Skill（技能）、MCP 和智能体不放在这里，统一进入 [`../Agent/`](../Agent/)。

## 目录

| 路径 | 内容 |
|------|------|
| [`product/`](product/) | 产品需求、阶段范围、验收标准、实施计划 |
| [`design/`](design/) | UI 设计规范、主题、交互说明、设计审计 |
| [`resources/`](resources/) | 运行时资源说明、工具链来源、许可证记录 |
| `flows/` | 预留：流程图、Mermaid、架构图 |
| `deliverables/` | 预留：PPT、PDF、Excel、报告等交付物 |
| `research/` | 预留：调研记录、竞品分析、开源方案评估 |

## 文档归档规则

- 产品目标、范围、验收标准放 `product/`。
- UI 规范、主题和界面设计放 `design/`。
- 架构图、流程图和 Mermaid 图放 `flows/`。
- PPT、PDF、Excel 和正式报告放 `deliverables/`。
- 临时草稿放 `tmp/`，确认有长期价值后再移动到对应目录。
