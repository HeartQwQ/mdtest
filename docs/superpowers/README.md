# Superpowers 工作流

本仓库开发遵循 [Superpowers](https://github.com/obra/superpowers) 技能链。

**产品需求总览**：[`docs/requirements.md`](../requirements.md)

## 计划文档

实现计划放在：

```
docs/superpowers/plans/YYYY-MM-DD-<feature-name>.md
```

## 流程摘要

| 阶段 | Skill |
|------|--------|
| 需求与设计 | brainstorming |
| 实现计划 | writing-plans |
| 隔离开发 | using-git-worktrees（可选） |
| 编码 | test-driven-development |
| 执行计划 | executing-plans / subagent-driven-development |
| 排错 | systematic-debugging |
| 完成前 | verification-before-completion |
| 评审 | requesting-code-review |
| 收尾 | finishing-a-development-branch |

项目级约定见 `.cursor/rules/superpowers-workflow.mdc`。
